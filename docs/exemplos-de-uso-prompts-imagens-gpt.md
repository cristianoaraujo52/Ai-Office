# Prompts para gerar os 28 slides — Exemplos de Uso

Use cada prompt separadamente no gerador de imagens do GPT. Exporte em PNG, proporção 16:9, preferencialmente com 1536 × 864 pixels.

## Regras gerais

- Gere apenas uma imagem por solicitação.
- Preserve exatamente os textos curtos escritos entre aspas.
- Não acrescente textos, logotipos, marcas-d’água ou botões que não foram pedidos.
- As telas são simulações didáticas, não cópias exatas das interfaces reais.
- Se algum texto sair errado, peça ao GPT para corrigir apenas o texto, mantendo toda a composição.
- Nomeie os arquivos conforme indicado em cada slide.

Antes de enviar os arquivos para o projeto, confirme:

1. A imagem está em proporção 16:9.
2. O título e os quatro passos estão escritos corretamente.
3. Nenhum texto foi cortado.
4. A interface parece simulada e didática.
5. A imagem não possui marca-d’água.
6. O nome do arquivo corresponde ao indicado.
7. Há contraste suficiente para leitura em telas menores.
