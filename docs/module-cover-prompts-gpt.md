# Prompts Para Capas Dos 14 Modulos

Objetivo: criar capas novas, totalmente diferentes entre si, estilizadas e conectadas ao conteudo de cada modulo da IA Office Academy.

## Configuracao Recomendada

- Dimensao: `3840x2160 px`
- Proporcao: `16:9 exato`
- Formato inicial: `PNG`
- Formato final para o app: `WEBP`
- Composicao: assunto principal no centro, com margem segura nas bordas
- Uso no app: capas exibidas em containers `aspect-video` com `object-cover`
- Texto na imagem: nao usar texto, titulos, frases, logos ou marcas
- Estilo geral: capas premium, autorais, com visual forte de conteudo

## Negative Prompt Geral

Use junto com todos os prompts:

```text
text, letters, words, captions, subtitles, logo, watermark, signature, brand names, real people, photorealistic human faces, low quality, blurry, distorted objects, generic AI background, random neural network wallpaper, excessive purple blue gradient, cluttered composition, tiny unreadable UI text, cropped main subject, important elements near edges
```
